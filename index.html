Apa itu Cloud Computing?

Cloud Computing atau Komputasi Awan adalah revolusi digital yang memungkinkan kita mengakses sumber daya IT—seperti server, penyimpanan, dan aplikasi—melalui internet dengan model pay-as-you-go. Tanpa perlu memiliki infrastruktur fisik yang mahal, siapa saja bisa berinovasi dengan cepat.

01

Skalabilitas Tinggi

Menambah atau mengurangi sumber daya sesuai kebutuhan dalam hitungan menit.

02

Efisiensi Biaya

Hanya membayar apa yang Anda gunakan tanpa biaya pemeliharaan hardware fisik.

03

Akses Global

Akses data dan aplikasi Anda dari mana saja di seluruh dunia selama ada internet.

Laporan Proses
1

Pertemuan 1: Instalasi VirtualBox & Debian

Pada pertemuan pertama, fokus utama adalah mempersiapkan lingkungan virtualisasi. Kami menggunakan Oracle VM VirtualBox sebagai platform hypervisor. Setelah itu, dilakukan instalasi Debian 12 Server. Proses ini meliputi pengaturan partisi harddisk virtual, konfigurasi hostname, serta pengaturan user root dan password untuk keamanan sistem operasi.

  • • Download & Install VirtualBox terbaru.
  • • Membuat VM baru dengan RAM minimal 1GB.
  • • Instalasi OS Debian (Text-mode/CLI).
2

Pertemuan 2: Konfigurasi IP Address Static

Pertemuan kedua membahas tentang networking dasar di Linux Server. Kami mempelajari cara mengubah konfigurasi jaringan dari DHCP (otomatis) menjadi Static IP. Hal ini penting agar server memiliki alamat tetap yang tidak berubah-ubah. Konfigurasi dilakukan pada file /etc/network/interfaces dengan menentukan address, netmask, dan gateway secara manual.

# Contoh Konfigurasi:

auto enp0s3
iface enp0s3 inet static
    address 192.168.10.1
    netmask 255.255.255.0
3

Pertemuan 3: Membangun Web Server

Pada tahap ini, kami mengimplementasikan layanan web server menggunakan Apache2. Proses dimulai dengan mengupdate repositori dan menginstal paket apache2 via apt-get. Setelah terinstal, kami mencoba memodifikasi file index.html di direktori /var/www/html/ untuk menyesuaikan tampilan web server sesuai kebutuhan praktikum.

Command Utama:

apt install apache2 -y
