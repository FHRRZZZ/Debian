Apa itu Cloud Computing?

Cloud Computing atau Komputasi Awan adalah revolusi digital yang memungkinkan kita mengakses sumber daya IT—seperti server, penyimpanan, dan aplikasi—melalui internet dengan model pay-as-you-go. Tanpa perlu memiliki infrastruktur fisik yang mahal, siapa saja bisa berinovasi dengan cepat.

01

Skalabilitas Tinggi

Menambah atau mengurangi sumber daya sesuai kebutuhan dalam hitungan menit.

02

Efisiensi Biaya

Hanya membayar apa yang Anda gunakan tanpa biaya pemeliharaan hardware fisik.

03

Akses Global

Akses data dan aplikasi Anda dari mana saja di seluruh dunia selama ada internet.

Pertemuan 1: Pondasi Virtualisasi & OS Setup

Pada pertemuan pertama, kami meletakkan dasar infrastruktur dengan mengeksplorasi konsep Virtualisasi. Kami menggunakan Oracle VM VirtualBox sebagai Hypervisor tipe-2. Fokus utama adalah instalasi Debian 12 Server (Bookworm) dalam mode CLI (Text-mode) untuk efisiensi sumber daya. Kami mempelajari cara mengalokasikan RAM, membuat Virtual Disk (VDI), dan mengatur Network Adapter (NAT untuk akses internet sistem dan Host-Only untuk komunikasi antar mesin lokal).

Key Takeaways:

  • • Konfigurasi Virtual Hardware (Min. 1GB RAM).
  • • Partisi Harddisk (Root, Swap, Home).
  • • Instalasi OpenSSH Server untuk remote access.
  • • Setup Mirroring ke server lokal Indonesia.
Pesan & Kesan
"Awalnya cukup membingungkan saat membagi partisi manual, tapi rasa puas muncul ketika pertama kali melihat login prompt CLI Debian yang bersih. Ini adalah langkah pertama menjadi SysAdmin!"

Pertemuan 2: Arsitektur Jaringan Server

Masuk ke inti server, kami mempelajari Networking. Penting bagi sebuah server untuk memiliki alamat tetap, maka kami mengonfigurasi Static IP Address. Kami memodifikasi file konfigurasi utama di /etc/network/interfaces. Selain itu, kami mengatur DNS Resolver pada file /etc/resolv.conf agar server dapat mengenali domain internet.

/etc/network/interfaces

# Setting Static IP

auto enp0s3
iface enp0s3 inet static
    address 192.168.10.10/24
    gateway 192.168.10.1
    dns-nameservers 8.8.8.8 1.1.1.1
Pesan & Kesan
"Sangat menantang saat melakukan troubleshooting jaringan. Salah satu titik koma atau angka saja bisa membuat koneksi terputus. Namun, saat perintah 'ping' berhasil memberikan balasan, rasanya sangat melegakan!"

Pertemuan 3: Arsitektur DNS Server (BIND9)

Pada pertemuan ketiga, kami berfokus pada pemahaman konsep Domain Name System (DNS). Kami mempelajari bagaimana sistem ini bekerja di latar belakang untuk menerjemahkan alamat IP yang rumit menjadi nama domain idad.com yang mudah diingat. Diskusi mencakup hierarki domain, peran Root Server, hingga bagaimana Resolver lokal berinteraksi dengan server otoritatif.

Pesan & Kesan
"Materi DNS ini sangat dalam. Memahami bagaimana hierarki domain bekerja memberikan perspektif baru tentang internet. Sangat puas ketika 'nslookup idad.com' berhasil!"
4

Pertemuan 4: Web Hosting & Virtual Host

Setelah memahami konsep DNS, pertemuan keempat adalah tahap eksekusi teknis. Di sini kami melakukan Konfigurasi DNS & Web Hosting secara bersamaan. Kami menerapkan pengaturan domain idad.com pada BIND9 dan menghubungkannya dengan Virtual Host Apache2.

1. Konfigurasi Zone DNS (named.conf.local)

zone "idad.com" {
    type master;
    file "/etc/bind/db.idad";
};

2. Database Zone & TTL (db.idad)

$TTL 604800
@ IN SOA idad.com. root.idad.com. (
    2024050401 ; Serial
    604800 ; Refresh
)
@ IN NS idad.com.
@ IN A 192.168.10.10
www IN A 192.168.10.10

Main Commands:

sudo apt install apache2 -y sudo a2ensite idad.conf

"Melihat website idad.com aktif di browser adalah penutup praktikum yang sangat memuaskan."
